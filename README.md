# Projeto 1 - Automatizador de Planilhas

Automatiza tarefas repetitivas de Excel usando Python e Pandas.

## Tecnologias
- Python
- Pandas
- OpenPyXL
- Git/GitHub

## O que faz
Lê planilhas, limpa dados e gera relatórios automaticamente.

## Como rodar
pip install pandas openpyxl
python main.py
